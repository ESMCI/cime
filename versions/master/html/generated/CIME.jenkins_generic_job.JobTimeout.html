CIME.jenkins_generic_job.JobTimeout

class CIME.jenkins_generic_job.JobTimeout(seconds, clock=None)[source]

Bases: object

Tracks the wall-clock budget of a jenkins_generic_job run.

Keeps the user informed of how much of the budget each stage has left and records whether the budget ran out so a timed-out job is reported clearly and never reported as a success.

Args:

seconds: Total budget in seconds, or None for no limit. clock: Callable returning the current time in seconds. Defaults to

time.time; injectable for testing.
